하위 재료 레시피 입력

한 줄에 하위 재료 하나씩 입력해 주세요.
예: 박력분 200g, 설탕 100g, 버터 150g, 달걀 2개

레시피 구성

상위 재료 안에 하위 재료를 등록하세요. 원가는 하위 재료의 사용량을 기준으로 계산됩니다.

전체 레시피 사용

상위 재료의 총원가와 단가를 확인하고, 전체 레시피에 사용할 양을 입력하세요.

하위 재료 전체 사용량

여러 상위 재료에 중복 사용된 하위 재료를 이름과 단위별로 합산합니다.

레시피를 추가하면 하위 재료별 전체 사용량과 원가가 표시됩니다.
